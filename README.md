# 📚 Library PWA System

## 📖 About
This project is a study-oriented application aimed at developing a Progressive Web App (PWA) for a library system.  
The main goal is to explore modern web technologies while building a functional and scalable solution.

## ⚙️ Functionalities
- Basic authentication system  ✅
- User registration  ✅
- Book stock management  
- Borrowing system  
- Role-based access control  

## 🧱 Tech Stack

### 🔙 Backend
- Laravel  

### 🎨 Frontend
- React  
- React Router  

### 🗄️ Database
- PostgreSQL
